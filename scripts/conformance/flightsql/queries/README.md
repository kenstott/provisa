Query overrides for the ADBC validation suite, merged over its base cases part by part.

Each `type/select/<case>.txtcase` is generated by `../fixtures.py overrides` from the suite's
case and checked against it by `fixtures.py seed`, so it cannot drift from the pinned suite:

- every case's `catalog_schema`: its table's own columns, then the two link columns every model
  table carries (`_name_`, `_domain_`), which is how the table is listed;
- the ten timestamp and ten timestamptz cases, which share two table names with different
  contents, also override `query` and `metadata` (`[setup] drop`, which the suite reads the
  table schema from) to name the table the fixture model holds for the case.

No other case is overridden.
