Cloud Security Policy

Owner: the Chief Information Security Officer. Applies to every account the company runs on Azure, AWS and Google Cloud.

4.2 Disk encryption with customer-managed keys

Every disk attached to a virtual machine is encrypted with a customer-managed key (CMEK) held in the company's key service for that cloud. A disk encrypted only with the provider's own key does not meet this control.

4.3 Exceptions

A resource may be excused from a control only by an exception the CISO approves. An exception is recorded as an incident in the Policy exception category that names the resource and cites this section. It expires 90 days after it is opened, and the resource then meets the control or is covered by a new exception.

4.4 Key rotation

Every customer-managed key used for disk encryption is rotated at least once every 365 days.

5.1 No public addresses on database servers

A virtual machine that runs a database has no public IP address. It is reached only from the company's private networks.

5.2 Private storage

No storage bucket or storage account allows public access.

6.1 Remediation deadlines

A violation is fixed within a deadline set by its incident's priority, counted from the day the incident is opened: 7 days for priority 1 (critical), 14 days for priority 2 (high), 30 days for priority 3 (moderate) and 90 days for priority 4 (low).

7.1 Audit log retention

Every cloud account keeps its control-plane audit log for at least 365 days.

Revision of 2026-03-01: section 4.1, which allowed provider-managed keys on disks of non-production machines, is withdrawn. Section 4.2 applies to every disk.
